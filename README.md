# شجرة العائلة

تطبيق شخصي لتسجيل العائلة ورسم شجرتها وطباعتها. يعمل دون إنترنت، والبيانات تبقى في الجهاز فقط ولا تخرج منه إلا بملف يصدّره المستخدم.

- **أندرويد:** ملف `shajara.apk` في صفحة الإصدارات (Releases)، ويُبنى تلقائيًا بلا صلاحية إنترنت.
- **آيفون:** نسخة الويب على GitHub Pages، تُضاف إلى الشاشة الرئيسية وتعمل دون اتصال بعد أول فتح.

## المحتويات

| المجلد | ما فيه |
|---|---|
| `web/` | التطبيق نفسه (HTML وJavaScript بلا أدوات بناء) |
| `android-shell/` | غلاف أندرويد (Capacitor) وأيقوناته وسكربت التعديل |
| `tools/` | تجهيز نسخة الويب والأيقونات |
| `tests/` | اختبارات آلية على مقاس الجوال |
| `.github/workflows/` | بناء ملف APK ونشر نسخة الويب |

الخط: خط ثمانية، مستخدم بإذن صاحبه.
